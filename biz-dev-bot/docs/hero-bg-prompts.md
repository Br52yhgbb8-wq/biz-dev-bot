# Mercury 主页背景图生成词

> 基调：Apple 极简平面化，蓝白渐变低饱和度，科技感抽象几何
> 生成工具：MiniMax / Gemini / Midjourney
> 尺寸：1920×1080（16:9）
> 数量：12 张，可通过 CSS crossfade 或 gsap 循环播放形成动态背景

---

## 通用参数

所有图片建议统一使用以下描述词（放在每张 prompt 最前面或作为负面提示）：

- **风格**：Flat design, minimal, clean, Apple aesthetic, soft gradient, low saturation, technical yet elegant, 8k render
- **颜色**：Blue-gray #7A899C → white → very light blue (#E8EDF2), low saturation
- **排除**：No text, no logo, no photos, no realistic people, no dark mode, no neon, no high contrast, no noise

## 使用方式

### 方案 A：CSS crossfade 幻灯片
将 12 张图按顺序放入 `public/images/bg/frame-01.jpg` ~ `frame-12.jpg`，用 CSS animation 循环播放：

```css
@keyframes bgCycle {
  0%, 7% { opacity: 1; }
  8.33%, 99% { opacity: 0; }
}
.frame { position: absolute; inset: 0; animation: bgCycle 24s infinite; }
.frame:nth-child(2) { animation-delay: 2s; }
/* ...每帧间隔 2s */
```

### 方案 B：GSAP 交叉淡入淡出
```js
const frames = document.querySelectorAll('.bg-frame')
let current = 0
setInterval(() => {
  gsap.to(frames[current], { opacity: 0, duration: 0.8 })
  current = (current + 1) % frames.length
  gsap.to(frames[current], { opacity: 1, duration: 0.8 })
}, 2000)
```

### 方案 C：直接替换 video 背景
如果你更想用静态图替代当前的 hero.mp4 视频，可以把这套图片直接铺在 Hero 区域代替 `<video>` 标签。
